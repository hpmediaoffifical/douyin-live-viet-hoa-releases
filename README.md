# Douyin LIVE Việt hóa — HP Media

Bộ Việt hóa và tinh gọn giao diện **Douyin LIVE (直播伴侣)** cho creator Việt Nam:
tập trung vào **làm đẹp, chỉnh dáng, filter, hiệu ứng, phông xanh, thư viện**.

**Dịch bởi [HP Media](https://hpvn.media/) — Tác giả: Nguyễn Hoàng Phụng — [Đăng ký Creator TikTok LIVE](https://www.facebook.com/hpvn.media)**

## Cài đặt
1. Cài **Douyin LIVE (直播伴侣)** bản gốc: https://streamingtool.douyin.com/
2. Tải file `DouyinLIVE-VietHoa-Setup-x.y.z.exe` mới nhất ở mục **[Releases](../../releases/latest)**.
3. Thoát Douyin LIVE (chuột phải icon ở khay hệ thống → Thoát), chạy file cài đặt.

Bộ cài đã kèm mọi thứ cần thiết, không cần cài thêm phần mềm nào.

## Tự cập nhật
Nếu chọn *"Tự động cập nhật"* khi cài, bản Việt hóa tự cập nhật âm thầm, không cần làm gì:
- Mở Douyin LIVE: tự kiểm tra bản Việt hóa mới; có bản mới thì **tự cài khi bạn tắt Douyin LIVE**.
- Đăng nhập Windows: tự kiểm tra cập nhật và tự Việt hóa lại khi Douyin LIVE vừa tự cập nhật phiên bản mới.

Có thể kiểm tra thủ công: Start Menu → **HP Media → Kiểm tra cập nhật**.

## Khôi phục / gỡ bỏ
- Start Menu → **HP Media → Khôi phục bản gốc (tiếng Trung)**.
- Gỡ cài đặt (Settings → Apps) tự trả Douyin LIVE về bản gốc.
